# Release coverage and bridge timing

The Release scheme's autogenerated test plan enables coverage even for ordinary
builds. Setting `codeCoverageEnabled="NO"` alone does not override that plan.
Release therefore disables both coverage and test-plan autocreation in its scheme,
while the project's Release configuration sets `ENABLE_CODE_COVERAGE` and
`CLANG_COVERAGE_MAPPING` to `NO`. The scheme change also prevents linked Swift
packages from retaining instrumentation. Project settings alone left profile
sections in the executable.

Development retains its autogenerated plan and coverage. Both schemes' test
actions still select Debug, where `ENABLE_TESTABILITY=YES` supports `@testable`
imports. Coverage tests should use Development. Release already resolves to
`ENABLE_TESTABILITY=NO`, Swift `-O` with whole-module optimization, Clang `-Os`,
and `ENABLE_NS_ASSERTIONS=NO`; those settings need no change.

Verify with an unsigned Release **build**, then inspect the executable with
`otool -l` and `nm`. There should be no `__llvm_prf*` or `__llvm_cov*` sections
and no `__llvm_profile` symbols. Check both schemes with `-showBuildSettings`:
Release should report both coverage settings as `NO`, Development as `YES`.

## Supervisor live probe

Evaluate the following expression through the existing running app's devbridge
eval before and after deployment. Run six separate evaluations per build and
compare the median `nsPerIteration` for each operation. Keep the foreground app,
display setup, logging, and system load consistent. Each batch runs synchronously
on the app's main thread; let it finish between evaluations.

The probe only reads native state. Its module references, warmup, and result
serialization sit outside the timed loops. `absoluteTime()` returns nanoseconds.
Screen and application rows include the additional bridge reads shown explicitly
below; timings are per loop iteration, not per individual bridge crossing.

```javascript
(() => {
  const timer = hs.timer, mouse = hs.mouse, screen = hs.screen;
  const application = hs.application, pasteboard = hs.pasteboard;
  if (!screen.main()) throw new Error("No main screen available");
  const iterations = 100000;
  const operations = [
    ["timer.absoluteTime", () => timer.absoluteTime()],
    ["mouse.position.x", () => mouse.position().x],
    ["screen.main.frame.w", () => screen.main().frame.w],
    ["application.frontmost.pid", () => application.frontmost()?.pid ?? 0],
    ["pasteboard.changeCount", () => pasteboard.changeCount],
  ];
  return JSON.stringify(operations.map(([operation, read]) => {
    let last;
    for (let i = 0; i < 1000; i++) last = read();
    const start = timer.absoluteTime();
    for (let i = 0; i < iterations; i++) last = read();
    const elapsed = timer.absoluteTime() - start;
    return { operation, iterations, ms: elapsed / 1e6,
      nsPerIteration: elapsed / iterations, last };
  }));
})()
```
