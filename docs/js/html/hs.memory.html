hs.memory

Module

Inspect the current process's memory and explicitly request garbage collection and allocator relief. Loading this module does not collect or release memory.

Properties

This module has no properties.

Methods

hs.memory.stats() -> {[key: string]: any}

Returns a snapshot of process, malloc, and JavaScript heap memory. All sizes are bytes. `footprint` is task_vm_info's phys_footprint; `footprintPeak` is included when the kernel supplies its peak ledger. `malloc` contains `sizeInUse`, `sizeAllocated`, `blocksInUse`, and `zones`. The zones array has objects with `name` and those same three counters. Totals sum every registered malloc zone, including zones with duplicate names. `js` contains `heapSize`, `heapCapacity`, `extraMemorySize`, `objectCount`, `protectedObjectCount`, `globalObjectCount`, `protectedGlobalObjectCount`, and the name-to-count maps `objectTypeCounts` and `protectedObjectTypeCounts`. The protected type map is empty when JSC does not provide it. `js` is null if its private statistics symbol is unavailable. JSC figures cover the calling context's VM; process and malloc figures cover the entire process. Sampling itself allocates memory; the counters are not an atomic snapshot.
Declaration
hs.memory.stats() -> {[key: string]: any}
Returns
{[key: string]: any}
A plain object containing `footprint`, optional `footprintPeak`, `malloc`, and `js`. Throws if task or malloc statistics cannot be read.
Example
console.log(JSON.stringify(hs.memory.stats()))

hs.memory.relieve(opts) -> {[key: string]: any}

Runs synchronous full JavaScript GC, then requests maximal malloc relief. Both treatments default to true. GC runs on the calling JS thread. If its private symbol is unavailable, GC is skipped and `gcMs` is zero. Skipping malloc relief leaves `mallocReleased` and `reliefMs` zero. Timings are in milliseconds; footprints and released memory are bytes. Footprints are measured immediately before, after GC, and after malloc relief, even when a treatment is skipped. JSC releases pages asynchronously, so footprints need not decrease. This call does not wait for those pages to be returned.
Declaration

Parameters

Example
